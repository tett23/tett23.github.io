Aleph は、本と PDF をつくることに特化した執筆・組版環境です。縦書きの原稿を書き、Golem で組んだページを 300 dpi で確かめ、プロットと進み具合を一つの画面で扱えます。

ダウンロード GitHub macOS（Apple Silicon）・プレリリース

SCREENS書いて、組んで、確かめる

原稿の編集から、ページの仕上がり、作品の設計まで。v1.0.0-rc3 のアプリで撮った画面です。

01エディタ

縦書きと横書きを一つのエディタで。右のパネルに、シートの目標、キーワード、書くこと、ノートを置きます。

02ページのプレビュー

横書きのエディタの右に、Golem で組んだページを 300 dpi で描いて並べます。

03プロット

シーンを表で書き、サブプロットごとの時間の流れをガントチャートで見渡します。

04設定

外観、保存と Git、原稿用紙の換算、同梱の Golem と shem などを、一つの画面で設定します。ページの解像度は 300 dpi にしています。

FEATURES本をつくるための機能

  • 縦書きと横書きのエディタ

    一つのエディタで、縦書きと横書きを切りかえて書きます。

  • ページのプレビュー

    Golem で組んだ PDF を shem で描いて並べます。解像度は設定で決めるか、枠の幅と画面の倍率から自動で決めます。別のウィンドウにも出せます。

  • ビルド

    ツールバーの金槌で、ターゲット、プロファイル、トンボを選んで、PDF、HTML、EPUB、テキストを書き出します。⇧⌘B で前回と同じ選び方でビルドします。

  • 本文のプレビュー

    Golem の HTML の出力で、見出し、ルビ、表を組んだ本文を読めます。

  • 診断と補完

    golem lsp とつながり、誤りの診断、補完、ホバー、整形を使えます。開いているシートとプロジェクトの診断は、問題のパネルに集まります。

  • 改ページの見積もり

    原稿のどこでページが改まるかの見積もりを出します。

  • プロットとガントチャート

    シーンを表で書き、サブプロットごとの時間の流れをガントチャートで見渡します。

  • 目標の字数と原稿用紙

    シートごとに目標の字数を立て、字数、ワード数、原稿用紙の枚数を数えます。

  • 書くこととノート

    シートの横に、書かなくてはいけないことのチェックと、ノートを置きます。

  • 保存と Git

    自動で保存し、1 日 1 回自動でコミットします。差分、コミット、push、pull も、アプリの中の Git のパネルで。

  • ウィキリンクと検索

    シートをウィキリンクとキーワードで結び、ワークスペース全体を検索して置換します。

  • 共有ライブラリ

    フォント、Golem のプラグイン、関数を一か所に置き、プロジェクトをまたいで使います。

  • いろいろな形式

    Markdown、CSV、TSV、TOML、JSON の仲間、SVG、Mermaid、PDF、画像も開けます。Markdown の原稿は .gm に変換できます。

POWERED BY GOLEM組版は Golem に任せる

Aleph のページのプレビューは、組版システム Golem が組んだ PDF そのものです。Golem と、PDF を画像に描く shem をアプリに同梱しているので、別に入れる必要はありません。v1.0.0-rc3 は golem v0.1.0-rc4 と shem v0.1.0-rc7 を同梱しています。

INSTALLインストール

  1. Aleph-v1.0.0-rc3-aarch64-macos.zip と SHA256SUMS をダウンロードし、照合します。 
    shasum -a 256 --ignore-missing -c SHA256SUMS
  2. zip を展開し、Aleph.app を「アプリケーション」に移します。
  3. Aleph は公証を受けていないので、ダウンロードしたままでは macOS が開くのを拒みます。一度だけ、次を実行します。 
    xattr -dr com.apple.quarantine /Applications/Aleph.app

配布物は Apple Silicon の Mac のためのものだけです。リリースノートは v1.0.0-rc3 のリリースにあります。
