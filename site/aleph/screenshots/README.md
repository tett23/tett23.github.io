# Aleph のスクリーンショット

[ADR 0002](../../../docs/adr/0002-aleph-page.md) のカルーセルに使う、Aleph の 4 つの画面の画像。版は [ADR 0006](../../../docs/adr/0006-aleph-page-for-v1-0-0-rc4.md) で決めた。

## 撮り方

- 版：Aleph v1.0.0-rc4。リリースの `Aleph-v1.0.0-rc4-aarch64-macos.zip` の `Aleph.app` で撮る。
- macOS をダークモードにし、Aleph の外観を「OS に合わせる」にする。
- ウィンドウの大きさは 1280 × 800 ポイントにし、Retina の画面で撮る（2560 × 1600 画素）。
  - 2026-11-10 に v1.0.0-rc4 で撮ったときは、等倍の外部ディスプレイ（DELL S2721QS）しかなかったので、1280 × 800 画素になった。Retina の画面で撮り直せば、[ADR 0002](../../../docs/adr/0002-aleph-page.md) のとおり 2560 × 1600 画素になる。
- `screencapture -x -o -l <ウィンドウ ID>` で、ウィンドウだけを影なしで撮る。
- 設定の「ページの解像度」を 300 dpi にする。ページのプレビューは、その設定で描いたものを撮る。

| ファイル | 画面 |
| --- | --- |
| `editor.png` | エディタ（縦書き。右のパネルに目標、キーワード、書くこと、ノート） |
| `preview.png` | ページのプレビュー（横書きのエディタの右に、300 dpi で描いたページ） |
| `plot.png` | プロット（シーンの表と、サブプロットごとのガントチャート） |
| `settings.png` | 設定（「プレビュー」の項目。ページの解像度が 300 dpi） |

## 2026-11-10 に v1.0.0-rc4 で撮った手順

- 手元のほかの Aleph の設定に触れないよう、`HOME` を空のディレクトリにして `Aleph.app/Contents/MacOS/aleph` を直接起動した。設定は `config.json` に、ワークスペースを見本のディレクトリだけ、`dpi` を 300、`theme` を `auto` と書き、`window.json` で大きさを決めた。
- エディタ：ツリーで「一」（`chapters/01.gm`）を開き、ツールバーの「縦」を押した。
- ページのプレビュー：ツールバーの「横」と「ページ」を押し、右のパネルを畳んだ。
- プロット：リボンのプロットのアイコンを押した。
- 設定：リボンの設定のアイコンを押し、「プレビュー」を選んだ。

## 見本のプロジェクト

- 小林多喜二『蟹工船』（青空文庫、図書カード No.1465、https://www.aozora.gr.jp/cards/000156/card1465.html）の冒頭を、章に分けたもの。Golem v0.1.0-rc4 のタグの `modules/golem-driver/test/fixtures/kanikosen/kanikosen.gm` を使う。
  - 底本：「蟹工船・党生活者」新潮文庫、新潮社、1953（昭和28）年6月28日発行、1968（昭和43）年5月30日32刷改版、1998（平成10）年1月10日89版
  - 入力：細見祐司
  - 校正：富田倫生
  - `kanikosen.gm` の末尾の「底本と作成者」の節に、青空文庫のテキストの記載のとおりにある。
- 章は `chapters/01.gm` から `03.gm` が「一」から「三」、`04.gm` が「底本と作成者」で、`style.toml` はフィクスチャーのものである。
- `plot.csv` と `.aleph/notes.json`（目標の字数とノート）は、撮るために作った見本である。

版を上げて見た目が変わったら、同じ手順で撮り直す。
