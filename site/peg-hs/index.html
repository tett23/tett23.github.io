Three things peg-hs cares about

Left recursion as written

Direct and indirect left recursion are accepted, with the semantics of bounded left recursion (Medeiros et al. 2014). The Lua 5.5 grammar keeps the manual's indirect left recursion and accepts all 34 files of the official test suite.

Generate where speed doesn't matter, write where it does

A rule without a type annotation or an action gets a generated type, so most rules need no Haskell at all. When a rule needs to be fast, give that rule a type and an action; the rest stays generated.

On an 800,000-character JSON document, generated types took 0.97× the time and 1.18× the peak memory of the typed grammar.

Errors at the grammar

GHC reports a type error in an action at the line and column of the .hpeg file, not somewhere in a generated module you never wrote.

One grammar, two styles

The calculator with addition, multiplication and parentheses. On the left, every rule has a type and an action that builds your own AST. On the right, the same grammar with neither: peg-hs generates the types shown above. A grammar can mix the two rule by rule.

Why another parser generator

Like happy and alex, peg-hs is a standalone generator, not a Template Haskell library. A generated module depends only on peg-runtime, and the same grammar generates the same module byte for byte, so the module can be committed and reviewed.

With parser combinators such as Parsec and Megaparsec, the grammar lives inside the program, and left recursion has to be rewritten by hand. In peg-hs the grammar is a file of its own, written the way the language is specified.

pest also keeps a PEG grammar in a file of its own. peg-hs differs in what a rule returns: each rule has a Haskell type, written or generated, so parse gives your AST directly.

With %syntax, peg-hs also builds a lossless syntax tree that keeps whitespace and comments, and with %recover it reports several errors in one parse, for formatters and language servers.

    Install

    GitHub Releases has peg-hs for Linux (x86-64) and macOS (arm64). Extract the archive and put peg-hs on your PATH. The release is a candidate; peg-hs is not on Hackage yet.

    tar xzf peg-hs-0.1.0-rc5-x86_64-linux.tar.gz
install peg-hs-0.1.0-rc5-x86_64-linux/peg-hs ~/.local/bin/
peg-hs --version

    On other platforms, build from source with GHC 9.10, 9.12 or 9.14 and cabal-install.

    git clone https://github.com/tett23/peg-hs.git
cd peg-hs
cabal install exe:peg-hs --installdir="$HOME/.local/bin" \
  --install-method=copy --overwrite-policy=always
