## 予定

- **Golem のページ**：[Golem](https://github.com/tett23/golem) のページとプレイグラウンドを、日本語で `golem/` に、英語で `golem/en/` に作る。中身は [tett23/tett23 の ADR 0005](https://github.com/tett23/tett23/blob/main/.github/docs/adr/0005-golem-page.md)、[tett23/tett23 の ADR 0006](https://github.com/tett23/tett23/blob/main/.github/docs/adr/0006-golem-preview-at-300-dpi.md)、[ADR 0001](adr/0001-golem-page-in-japanese-and-english.md) で決めてある。Golem の wasm のリリースを待っている。
- **Aleph のページ**：[Aleph](https://github.com/tett23/aleph) の紹介ページを、日本語で `aleph/` に作る。中身は [ADR 0002](adr/0002-aleph-page.md) で決めてある。
