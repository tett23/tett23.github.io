# ADR 0005: Golem のページの peg-hs の説明に Emet のパーサを足す

ステータス: 採択

## 文脈

[ADR 0001](0001-golem-page-in-japanese-and-english.md) は、Golem のページの関連プロジェクトの節で、peg-hs の説明を「Golem の `.gm` のパーサは peg-hs で生成している」と決めた。
作業者から、Emet のパーサも peg-hs で生成していることを書き足すよう指示があった。

Golem v0.1.0-rc4 のタグで確かめたことは次のとおり。

- `modules/golem-emet/grammar/Emet.hpeg` に Emet の文法がある。
- `modules/golem-emet/src/Golem/Emet/Generated.hs` の先頭に「This module was generated by peg-hs from modules/golem-emet/grammar/Emet.hpeg. Do not edit it by hand.」とある。
- `.gm` のパーサは、同じく `modules/golem-parser/grammar/Golem.hpeg` から生成している。

Emet は、Golem の関数を書く言語で、ページの拡張の節で紹介している（[ADR 0001](0001-golem-page-in-japanese-and-english.md)）。

## 実装すること

- 関連プロジェクトの節の peg-hs の説明を、次のとおりにする。ほかの点は [ADR 0001](0001-golem-page-in-japanese-and-english.md) のとおりにする。
  - 日本語：「PEG の文法から Haskell のパーサを生成します。Golem の `.gm` のパーサと、関数を書く言語 Emet のパーサは、peg-hs で生成しています。」
  - 英語：「Generates Haskell parsers from PEG grammars. Golem's parsers of `.gm` and of Emet, the language for functions, are generated with peg-hs.」

## 実装しないこと

- peg-hs のページに、Golem と Emet で使われていることを書くこと。指示は Golem のページの説明だけである。
- ほかの関連プロジェクトの説明を変えること。

## テスト設計

先に書いて失敗させてから実装する。

- `site/golem/page_test.ts`
  - 日本語と英語のページの関連プロジェクトの peg-hs の説明に、`.gm` と Emet の両方が書かれている。

## トレードオフ

- 説明が少し長くなる。代わりに、Golem の中で peg-hs が `.gm` のほかにも使われていることが伝わる。
